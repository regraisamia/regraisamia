🔬 About My Research

I am a PhD Researcher at Chouaib Doukkali University, Faculty of Sciences, LAROSERI Laboratory, working on:

Multimodal AI for Reliable Content-Based Medical Image Retrieval (CBIR) and Clinical Metadata

My doctoral research focuses on developing reliable multimodal retrieval approaches that combine visual information from medical images with clinical metadata. I am particularly interested in deep visual representations, multimodal learning, similarity search and graph-based retrieval.

My previous work includes DermFinder, a hybrid medical image retrieval system combining CNN and Vision Transformer representations, metric learning, dimensionality reduction and graph-based indexing.

🚀 Selected Projects

🔬 DermFinder – Hybrid Medical Image Retrieval System

Python · PyTorch · ResNet-50 · Vision Transformer · Metric Learning · PCA · Graph-Based Retrieval

A hybrid Content-Based Image Retrieval (CBIR) prototype for dermoscopic images, combining deep visual representations from CNN and Vision Transformer architectures.

Combined ResNet-50 and Vision Transformer features.

Applied metric learning for visual similarity representation.

Used PCA for feature compression and memory optimization.

Integrated graph-based indexing for efficient retrieval.

Achieved 0.9503 mAP@10 on the complete ISIC 2020 dataset.

Reduced feature memory footprint by 14.67×.

Achieved up to 5.91× retrieval acceleration.
